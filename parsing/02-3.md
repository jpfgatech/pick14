# Parsing: Fake miss-draw experiment (instructions/02-3.md)

## Intervention mechanics

Normal match draw+play (n_hand=3):
  hand before: 3 cards (some used in match)
  DRAW1: refill to 4
  PLAY:  discard 1 (kept best of 4) → 3 cards

Fake miss-draw:
  DRAW1*: refill to 3 only (not 4)
  PLAY:   discard 1 (chose from 3, not 4) → 2 cards
  extra:  draw 1 random → back to 3 cards

Net hand size: identical (3).  Score: identical.  Selection quality: lower.

## Why β(fake-miss-draw) < β(original)

β measures: P(match | draw last turn=1) − P(match | draw last turn=0)

| Baseline when Draw[n-1]=0 | Hand quality | β measures |
|---------------------------|-------------|------------|
| original (true pass)      | Poor (not refilled) | Large gap vs Draw=1 |
| fake-miss-draw (match, weakened refill) | OK (still refilled) | Small gap vs Draw=1 |

Because the fake-miss-draw counterfactual is "match but weakened draw", not
"true pass", the gap is smaller → β is lower.  This is an *underestimate* of
the true causal effect.

Between the two experiments (fake-draw vs fake-miss-draw), the true effect is
somewhere in between.

## Implementation notes

`apply_fake_miss_draw_match(state, match_move, rng)`:
1. `apply_move(state, match_move)` — normal match + DRAW1 to n_hand+1
2. If phase != PLAY or hand size ≤ n_hand: abort (deck sparse; treat as normal)
3. Pop 1 random card from hand → n_hand cards
4. `apply_move(state, caution_play(state))` → play 1 to pool → n_hand−1
5. Draw 1 from deck → n_hand cards

Returns True if intervention was applied; False if skipped.
