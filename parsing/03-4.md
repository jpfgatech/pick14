# Parsing: 03-4 linear regression (per-sum features, own score targets)

## Goal

OLS on two feature layouts; targets are the acting player’s **own** match-turn
**points** at N+1 and N+2 (not table point-gap).

## Simulation

Same as 03-3: deferred draws, GFP match + caution play, four snapshot kinds.

## Feature construction (s = 1 … 13)

### x1[s], x2[s] (Models A and B)

Enumerate all non-empty subsets of the hand; group by `game_value` sum in
1…13.

- **x1[s−1]** = max over subsets with sum **s** of `sum(score_value(card))`.
  If no subset, 0.

- **x2[s−1]** = if **k** = number of subsets with sum **s** is 0 or 1, then 0;
  else **2 × (k − 1)**.

### x3[s], x4[s] (Model B only)

Let **c = 14 − s**.  A *known category* requires: at least one subset with sum
**s** **and** at least one public card with `game_value == c`.

Let **H** = max hand score for sum **s** (same as x1 contribution for that s).
Let public scores for `game_value` **c** be sorted descending: `p0 ≥ p1 ≥ …`.

- **x3[s−1]** = **H + p0** if known category, else **0**.

- **x4[s−1]** = **H + p1** if at least **two** public cards of complement **c**,
  else **0** (no second target).

### Bias

Final feature in each vector = **1**.

## Targets

- **N+1:** `y = turns[p][j+1].pts` — points the current player scores on their
  **next** match turn.

- **N+2:** `y = turns[p][j+2].pts` when all players have index j+2; else row
  dropped for that horizon.

## Regression

`numpy.linalg.lstsq(X, y)`; R² = 1 − SS_res / SS_tot.

## Outputs (`artifacts/03-4/`)

- `r2_summary.png` — bar chart of R² for each model × horizon.  
- `coefficients.png` — for each run, **line plots** of OLS **β** vs. sum slot
  **s = 1…13** (one line per of x1, x2, x3, x4 as applicable) and a
  **dashed horizontal line** for the **bias** (intercept), with the numeric
  value in the legend.  
- `log.txt` — table + top |coef| + bias.
