# Parsing: 03-4 linear regression on per-sum hand features

## Goal

Fit two linear models on snapshot feature vectors (same simulation as 03-3:
deferred draws, 4 snapshot kinds) to explain N+1 and N+2 point-gaps.

## Feature vectors

For each snapshot, 13 sum slots (s = 1 … 13) are extracted from the hand and
public pool.  The bias term is always 1.

### Model A — 27 features  (13 × 2 + 1)

| Slot | Name | Definition |
|------|------|------------|
| 0–12 | `x1[s]` | 1 if any non-empty hand subset has `game_value` sum = s, else 0 |
| 13–25 | `x2[s]` | Count of non-empty hand subsets with sum = s |
| 26 | bias | 1 |

### Model B — 53 features  (13 × 4 + 1)

| Slot | Name | Definition |
|------|------|------------|
| 0–12 | `x1[s]` | same |
| 13–25 | `x2[s]` | same |
| 26–38 | `x3[s]` | `score_value` of best public card of `game_value` (14 − s); 0 if absent |
| 39–51 | `x4[s]` | `score_value` of 2nd-best public card of complement; 0 if < 2 |
| 52 | bias | 1 |

`x3` and `x4` use **actual card suits** (JOKER=5, HEART=4, SPADE=3, DIAMOND=2, CLUB=1).

## Outcomes

- **gap_N1** = `pts[p, j+1] − mean_q pts[q, j+1]` (same as 03-3)
- **gap_N2** = `pts[p, j+2] − mean_q pts[q, j+2]`; NaN-dropped for rows where j+2 is unavailable

## Regression method

Ordinary least squares via `numpy.linalg.lstsq`.  No regularisation.

## Outputs (`artifacts/03-4/`)

| File | Content |
|------|---------|
| `r2_summary.png` | Bar chart of R² for each (model × horizon) |
| `coefficients.png` | Horizontal bar charts (top-30 by \|coef\|) for all four regressions |

## Findings (20k games, 4p, n_hand=3, seed=0)

### Sample counts

1,035,869 N+1 samples · 926,277 N+2 samples (rows with j+2 available for all players).

### R² summary

| Model | Horizon | n | R² | RMSE |
|-------|---------|---|-----|------|
| A | N+1 | 1,035,869 | **0.1123** | 2.457 |
| A | N+2 | 926,277 | 0.0423 | 2.491 |
| B | N+1 | 1,035,869 | **0.1168** | 2.450 |
| B | N+2 | 926,277 | 0.0433 | 2.490 |

### Key observations

- **N+1 is predictably better than N+2**: R² drops from ~0.11 to ~0.04 going one
  horizon further out — the signal fades fast.

- **Model B improves only marginally over A** (0.1168 vs 0.1123 at N+1; 0.0433
  vs 0.0423 at N+2).  Adding `x3`/`x4` (the actual public card scores for known
  categories) adds only ~0.005 R².  Most of the predictive power is already in
  the **hand combinatorics** (`x1`, `x2`), not in the public card identity.

- **Dominant positive coefficients (`x1` terms, all models):** `x1[s=1]`
  (+1.27), `x1[s=2]` (+1.02), `x1[s=3]` (+0.80) — having a hand that can make
  low sums (which match high-value complements close to 13) strongly predicts
  good N+1 outcomes.  Low sums are rare, so their binary indicator is highly
  informative.

- **Dominant negative `x2` terms at high s:** `x2[s=10]` (−0.37), `x2[s=11]`
  (−0.33), `x2[s=12]` (−0.29) — more subsets summing near 13 is *negatively*
  associated with gap.  This reflects the snapshot structure: high-s subsets
  come from large-hand B2 snapshots (post-match play, 3 cards), which occur
  after a match was already scored, so the next turn's point gap is smaller.

- **`x4` in Model B** (second-best public card score) enters at −0.35 for
  `s=12` and −0.33 for `s=11`.  Negative sign: a second available public card at
  the high-sum complement means the public pool is rich in that category, but the
  regression picks up a confound — when there are two high-value public cards of
  the same complement, the current player may have matched once and the remaining
  pool is competitive, not advantageous.
