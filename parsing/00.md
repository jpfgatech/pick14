# Parsing — Instruction 00: Hand Card Value (Plus-Minus Regression)

**Artifacts:** `artifacts/00/` (default `--out-dir`)

## Understanding

Instruction 00 asks us to measure the *per-turn value* of each of the 54 cards.

**Model:**  
Player P holds card c for `x_P[c]` turns (snapshots taken at each MATCH-phase start).
Target is P's score minus the mean across all players — zero-sum, player-count agnostic.

Fitting `y ≈ X · pm` by OLS/ridge gives `pm[c]`: the marginal contribution to relative
score per turn the card is held.

**Strategy setting:**
- Random play was used as the first-pass data collection strategy, to avoid the
  distribution shift that would occur if the play policy itself depended on pm.
- The script later adds `--mode softmax` (data collected with softmax-guided play,
  preferring to discard low-pm cards) and `--mode iterate` (successive refinement).
- Match strategy is always GFP (`greedy_for_public_match`).

## What the script implements

| Expectation | Implementation |
|---|---|
| Cards with small digits more valuable | Confirmed by pm rank (A♣/♦/♠/♥ top) |
| Higher-point cards more valuable within digit | Visible in per-suit pm spread |
| 5s slightly less valuable (Joker competition) | Checked via digit-group bar |
| 9s slightly more valuable (5s available to match) | Checked via digit-group bar |
| x-axis = baseline play order | `iterate` mode sorts cards by (sv−gv, −gv) which is the v3 genome play priority |
| R² medium (≈0.20) | Expected; turns-held is a noisy proxy |
| High A-B run correlation (≥0.99) | Confirms pm values are stable despite modest R² |
| Multi-player consistency | 2p/3p/4p all run and cross-scatter is plotted |

## Gaps / notes

- Artifacts default to `artifacts/card_pm_turns_held/`; for project-rule alignment they
  should be under `artifacts/00/`. Update `--out-dir` if consistency matters.
- `CompositeSeatAgent` / `GreedyForPublicMatchPolicy` were imported but unused; removed.
- The "shrinkage" of OLS predictions (flat ŷ vs y scatter) is by design: optimal MSE
  forces `Var(ŷ) = R² × Var(y)`. Scaling ŷ would increase RMSE.
