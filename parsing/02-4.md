# Parsing: Points AR model (instructions/02-4.md)

## Change from 02-2

In 02-2 the time-series outcome is binary:
  Match[n] ∈ {0, 1}
  Draw[n-k] ∈ {0, 1}

Here we replace BOTH outcome and lagged predictors with the actual points
scored on that turn:
  Points[n] ∈ {0, match_capture_points(...)}
  → Points[n] = 0 if the player passed; ≥ 0 if a match was made

Model family (AR(p), original game only, no interventions):

  AR(1):  Points[n] = Base + β1·Points[n-1]
  AR(2):  Points[n] = Base + β1·Points[n-1] + β2·Points[n-2]
  AR(3):  Points[n] = Base + β1·Points[n-1] + β2·Points[n-2] + β3·Points[n-3]

## Two model families

The key distinction is which scale the predictor lives in:

  AR(p):    predictor = Points[n-1] (continuous, same units as outcome)
  Cross(p): predictor = Match[n-1] (binary 0/1, different scale from outcome)

For β, scaling works as follows.  If we rescale outcome by c and predictor by d:
  new_β = (c/d) × old_β

  AR:    c ≈ d ≈ 6  →  β unchanged (~0.21 from LPM)
  Cross: d = 1      →  β scales by c ≈ 6  →  β ≈ 1.2 pts per match event

Base always scales with c (outcome scale) only, so Base ≈ 0.50 × 6 ≈ 3.1 in both.

## Why R² did not increase

Points variance = Var(Match × MatchPoints)
  = match_ratio × Var(MatchPoints|match)  ← random card values (unpredictable)
  + match_ratio(1−match_ratio) × avg_pts² ← match/no-match variance

The β1 terms explain the match/no-match component (same as LPM, R² ~0.04-0.06).
The card-value variation is independent of lagged history → adds to denominator only.
Net: R² stays ~0.04, not higher.

AR predictor carries slightly more information than binary Cross predictor (encodes
both whether a match happened AND how many points), so AR R² ≥ Cross R².

## Data construction

For each player sequence of length T (MATCH-phase turns only):
  - Record Points[n] = match_capture_points if match, 0 if pass
  - Pre-pad Points with 3 zeros (no prior history before game starts)
  - For each turn n in 0…T-1:
      X_row = [1, Points[n-1], Points[n-2], Points[n-3]]
      y     = Points[n]

No interventions; use original game rules (GFP match + caution play).

## Expected outcomes

1. R² increases as window grows (AR(3) ≥ AR(2) ≥ AR(1))
2. β1 > β2 > β3 ≥ 0 (recent points predict more strongly)
3. All β significant (95% CI above zero)
4. Consistent across 2p / 3p / 4p

## 02-4 extension: fake-pass/fake-miss translation

To map the 02-3 effect into point units, keep the lagged predictor as Draw
(binary) and replace outcome with Points:

  Points[n] = Base + β1·Draw[n-1] + β2·Draw[n-2] + β3·Draw[n-3]

using the same three variants as 02-3:
  - original
  - fake-draw
  - fake-miss-draw (fake-pass style)

Expected:
  β1(fake-miss-draw) < β1(original) ≈ β1(fake-draw), with a similar ratio to
  the probability-space result (~0.13 / ~0.21 ≈ 0.62), but not exactly equal
  because point intensity on matched turns is also perturbed.
