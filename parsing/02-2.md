# Parsing: Match-draw time-series model (instructions/02-2.md)

## Why 02-1 gave b2 ≈ 0

In 02-1 we fit `score = a + b1·n_direct + b2·n_indirect`, where n_indirect counts
ALL draw+play opportunities (matches + pseudo-matches).  The result b2 ≈ 0.07–0.10
makes sense via do-calculus:

> Given the total number of matches is already in the model (through n_direct and
> n_indirect together), the "extra draw" has no RESIDUAL path to points — it only
> helps by enabling MORE matches, which are already counted.

So b2 measures the effect of an extra draw *conditional on* already having the same
match count.  That's zero (or near zero) by design.

---

## New question: does an extra draw increase the PROBABILITY of a future match?

Model: for each player, index their own MATCH-phase turns as 1, 2, …, T.

```
Match[n] = Base + β1·Draw[n-1] + β2·Draw[n-2] + β3·Draw[n-3]
```

- Match[n] = 1 if the player matched on their n-th turn, else 0
- Draw[n]  = 1 if an extra draw followed that turn
  - Original game:  Draw[n] = Match[n]  (draw only after a match)
  - Fake-draw game: Draw[n] = Match[n] OR pseudo-match[n]

Note the "same subscript" observation: in a single turn the match happens first,
then the extra draw.  So Draw[n] and Match[n] share index n, and the earliest
predictors are Draw[n-1], Draw[n-2], Draw[n-3].

This is a **Linear Probability Model** (OLS on binary outcome) — a valid starting
approximation and directly interpretable as probability increments.

---

## Data construction

For each player sequence of length T:
- Pre-pad Draw with 3 zeros (no prior draws before the game starts)
- For turn n in 0…T-1: row = [1, Draw[n-1], Draw[n-2], Draw[n-3]], label = Match[n]
- No post-padding (matches after game-end are not observable; adding zeros would
  dilute the baseline probability near the end)

---

## Two data sources

| Variant | Draw[n] | Score penalty |
|---------|---------|---------------|
| Original | = Match[n] | none |
| Fake-draw | = Match[n] ∨ pseudo-match[n] (p=0.5 on forced passes) | none |

The fake-draw variant injects Draw=1 events on turns where Match=0 (forced-pass
turns), giving variation independent of match-favorable hand compositions.  This
tests whether the β estimates from the original game reflect a true causal channel.

---

## Expected outcomes

1. β1 > β2 > β3 > 0: drawing more recently has a stronger effect.
2. Original and fake-draw betas should be similar (validates the causal story).
3. Consistent betas across 2p / 3p / 4p.
4. Base probability ≈ P(match in original game) ≈ 0.4–0.6.
