# Analysis of hand card value



## Background
Consider the play action of a game
Hand card position can be considered as a resource.
A basic, context independent play strategy would be:
- to evaluate the value of each card
- then spend the hand card positions on the highest valued cards

## Math Model
A model to evaluate the value of each card would be
- Treat each game card value as an unknown
- Given a full game record
- If a card stays for N turns before being played or matched
- It takes N resources
- It is expected to contribute to the player's performance by N times its value

- The player's performance is measured not by the absolute score,
- But by the difference between his score and the average of all players
- To ensure a total sum of zero, and to be compatible with all number of players

Make sure the simulation has sufficient samples to keep the coefficient matrix inversable

## Conditions

The player's strategy deeply affects the data sampling
For play strategy, options are: random play, baseline play, play by softmax probability, based on collected static value
- random play would be a good starting point for data collection purpose
- As we move to the closer to optimal strategies, data frequency will be disturbed
- We expect the highest value cards to be matched soon, and lowest value cards to be played soon, leaving the medium valued cards to stay in hand for most of the time
For match strategy, adopt baseline strategy for data collection purpose

## Expectations

### Linear regression output
We expect the value rank of cards to be similar to the baseline play strategy:
- Ace of Hearts is the highest valued card: best flexibility and highest points
- King of Club is the lowest valued card: worst flexibility and lowest point
- Cards with smaller digits are in general more valuable than higher digit peers
- Cards with higher poitns are in general more valuable than lower digit peers.
- Specificly, 5s are slightly less valuable, and 9s are slightly more valuable
- This is due to Jokers counting as digit 5, competing for 9s
- Plot the card rank, with baseline play order as the x axis. We are interested in its differences

### Linear regression consistency
The value of cards should be highly consistent over different simulations

### Multiplayer regression consistency
This would be interesting. We expect the relative order to be stable
- We expect more multi-card match over two card match in multi player games
- Therefore, flexibility should become a stronger factor
- E.g. the value gap between 3s, a somewhat flexible small digit, and 6s, a card that almost always matches 8, should become larger

### Performance Explained
We expect the linear regression model to be effective to some degree, i.e. medium R^2, on the final performance

### Output as play strategy
Using the static value rank as a play strategy may loose to the baseline play strategy
- Generally similar to the baseline strategy
- Insufficient comparison to recognize that King of club is strictly less valuable than King of diamond, etc.
