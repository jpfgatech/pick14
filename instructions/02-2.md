# Decompose the value of a match, continued

## Background

A match helps the player in two ways
- The direct scoring
- The opportunity to draw extra cards and play after draw, not vice versa
- The later allows the player to hold better hand cards and dump worse ones

## Explaination of previous result

Result of 02-1 actually makes sense
Extra drawing can only contribute points through more match
Since we've counted all match, the linear regression model is asking
How is extra drawing contribute to the final points, given the same match number
And the result should be exactly zero, since it's only intermediate towards points is turned off
A good proof of the do-calculus lecture

## Math Model

To refine our research, we conduct a regression model study
- The match event makes a time series of 1s (match made) and 0s (passed)
- The extra drawing also makes a time series of 1s and 0s
- The probability of match event is explained by a base probability
- Plus the contribution from previous extra drawings
- We attempt to compute the linear problem where
- Match[n] = Base + beta1 Draw[n-1] + beta2 Draw[n-2] + beta3 Draw[n-3]

Notice that:
- Since in a turn, Match happens before the extra drawing caused by it
- The Draw[n-1] and Match[n-1] has the same subscript

- As a initial effort we assume that only the last three extra draws contributes to the probability of match
- Beyond that window we assume the two events decorrelates

- At the beginning and the end of the game
- There is no extra drawing events, nor possible extra match to be caused
- We start our research by pre-padding Draw event vector with zero, and post-padding Match event vector with zeros
- Prepadding should be solid, but post padding might not be.

- Try with the fake extra draw in 02-1.md, but the 'removed points' does not apply

## Model refinement: remove β3

Also fit a 2-lag model (window of 2 instead of 3):

  Match[n] = Base + β1·Draw[n-1] + β2·Draw[n-2]

Results for β1 and β2 should be roughly the same, confirming lag 3 adds little.

## Sanity check

Count total matches and total match opportunities across all events.
List the match ratio (matches / opportunities) in each plot title.

We expect approximately:
  Base + Base·β1 + Base·β1·β2 ≈ ratio

(First-order approximation of the stationary match probability.)

Show Base alongside the β bars in each plot for both the 3-lag and 2-lag models.

## Expectations

- We expect that the effect of extra draw on probability of match should be obvious
- We expect all three betas to be positive. The earlier into history, the weaker the effect
- Original game rule and randomly set extra draws should give similar results
- Game records with different number of players should yield similar results
- Removing β3 should barely change β1 and β2
- Base + Base·β1 + Base·β1·β2 should be close to the empirical match ratio

## Findings

Simulated 10 000 games × {2, 3, 4} players, two variants: original and fake-draw.

**3-lag model (original, representative)**

| Condition | Base | β1 | β2 | β3 | ratio |
|---|---|---|---|---|---|
| 2p | 0.499 | +0.206 ± 0.004 | +0.052 ± 0.004 | +0.031 ± 0.004 | 0.685 |
| 3p | 0.513 | +0.216 ± 0.004 | +0.037 ± 0.004 | −0.002 ± 0.004 | 0.672 |
| 4p | 0.529 | +0.212 ± 0.004 | +0.033 ± 0.004 | −0.049 ± 0.004 | 0.655 |

Key results:
- **β1 ≈ 0.21**: an extra draw last turn raises the probability of matching this turn by ~21 percentage points.
- **β2 small and positive for 2p** (~0.04–0.05); near zero for 3p/4p — the effect decays fast.
- **β3 inconsistent in sign** and within noise; the 2-lag model is sufficient.
- **original ≈ fake-draw** for β1 (diff < 0.01): causal validation confirmed.  The injected fake-draws identify the same coefficient as the natural game variation.
- **Base ≈ 0.50–0.53**, consistent with a ~65–68 % empirical match ratio (first-order approx: Base + Base·β1 ≈ 0.60–0.63, accounting for most of the gap).
- Sanity-check formula `Base + Base·β1 + Base·β1·β2` approximates ratio to within 0.02–0.07, better for higher player counts where the game is longer and β2 is smaller.
