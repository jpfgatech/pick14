# Regression by number of match made

## Background
If we strip away the 'point' of a card and treat all cards as the same value the problem becomes much simpler
Making a match helps drawing more new cards and allow pick one card to play out of 4, not 3.
So, number of match is probably a strong factor to explain the final performance

## Math Model

We are interested in the contribution per match
Whether or not more match is itself a strong factor
And whether or not the points of each match averages out over a game
- We simulate game numbers, record number of match made per player
- Raw regression: regress number of match versus points scored for each game
- Raw-var regerssion: regress number of match versus points gap over average for each game
- Var regression: regress number of match over average versus points gap over average for each game

## Expectations

Check the R^2, how much does number of match explain performance, and whether maximizing number of match would be a good goal
Check the consistency across multiple player games for three different regressions
Report RMSE (residual std) alongside R^2 in the plot legend as a measure of the unexplained part in score units

## Findings

Simulated 10 000 games × {2, 3, 4} players (n_hand = 3, GFP + caution play).

| Player count | Raw R² | Var R² | Var slope (pts/match) | RMSE (Var) |
|---|---|---|---|---|
| 2p | 0.751 | 0.789 | +6.02 | 4.77 |
| 3p | 0.774 | 0.795 | +5.90 | 4.43 |
| 4p | 0.785 | 0.800 | +5.77 | 4.05 |

Key results:
- Number of matches explains **75–80 %** of score variance.
- Each additional match is worth approximately **5.8–6.0 points** (Var slope), consistent across player counts.
- Var R² is slightly *higher* than Raw R²: within-game relative match count predicts relative score more tightly than absolute match count.  This is because cross-game variation in absolute match count partly reflects game-length differences that cancel in the Var formulation.
- Maximising matches is a strong proxy goal for maximising score.
