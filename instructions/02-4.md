# Decompose the value of a match, continued (fake miss-draw)

## Background

In 02-2 and 3 we inspected the contribution of and extra draw and a miss-draw towards match probability
As an additional auto regression model, replace the 1/0 match event with points made

Try window of 3/2/1 betas. Hopefully we will see some greater R^2

Two model families are compared:
- **AR(p)**: Points[n] = Base + β1·Points[n-1] + …  (continuous predictor, points outcome)
- **Cross(p)**: Points[n] = Base + β1·Match[n-1] + …  (binary predictor, points outcome)

The distinction: in AR(p) both predictor and outcome change scale together, so β stays
unchanged from the binary LPM.  In Cross(p) only the outcome scales, so β scales like Base.

## Findings

Simulated 10 000 games × {2, 3, 4} players, windows 1/2/3 (original rules, n_hand=3).

**AR(p) — continuous predictor**

| Condition | Base | β1 | β2 | R² |
|---|---|---|---|---|
| 2p AR(1) | +3.25 | +0.199 ± 0.003 | — | 0.040 |
| 3p AR(1) | +3.12 | +0.201 ± 0.003 | — | 0.042 |
| 4p AR(1) | +3.05 | +0.188 ± 0.003 | — | 0.037 |

**Cross(p) — binary match predictor, points outcome**

| Condition | Base | β1 | β2 | R² |
|---|---|---|---|---|
| 2p Cross(1) | +3.17 | +1.29 ± 0.024 | — | 0.036 |
| 3p Cross(1) | +3.06 | +1.25 ± 0.022 | — | 0.036 |
| 4p Cross(1) | +3.02 | +1.11 ± 0.021 | — | 0.031 |

Key results:
- **AR β1 ≈ 0.19–0.20** — unchanged from the binary LPM.  Both predictor and outcome scaled together (~6×), so β (the slope) cancels and stays the same.  R² ≈ 0.04, not higher than the binary LPM.
- **Cross β1 ≈ 1.2–1.3 pts per match event** — scaled ~6× from 0.21.  Base also scaled ~6× (from 0.50 to 3.17).  β and Base scale by the same factor when the predictor stays binary and only the outcome changes units.  This is the dimensionally correct way to see the point-unit effect of an extra match on future scoring.
- **β2 in Cross(1) ≈ 0.20** for 2p, consistent with AR β2 (≈ 0.035) × avg match points (≈ 5.8).  The two families are numerically equivalent once units are accounted for.
- **R² did not increase** in either family (~0.04).  The variance in points is dominated by two independent components: (1) match/no-match (captured by β1) and (2) random card-value variation per match (unpredictable from lagged history).  Notably, AR R² is slightly higher than Cross R² because the continuous Points[n-1] predictor encodes both whether a match occurred AND how many points it was worth, carrying extra information about hand quality.
- **Additional lags add < 0.003 R²**; β3 is inconsistent in sign across player counts — same conclusion as in 02-2.

**Summary of β units across instructions**

| Model | Predictor | Outcome | β1 | Interpretation |
|---|---|---|---|---|
| 02-2 LPM | Draw ∈ {0,1} | Match ∈ {0,1} | ~0.21 | +21pp match prob per draw event |
| 02-4 AR(1) | Points[n-1] | Points[n] | ~0.20 | +0.20 pts per pt scored last turn |
| 02-4 Cross(1) | Match ∈ {0,1} | Points[n] | ~1.25 | +1.25 pts per match event last turn |

All three are measuring the same underlying effect: ≈ 0.21 match-probability × 5.8 pts/match ≈ 1.2 pts per draw/match event.

## Fake-pass (fake-miss-draw) translation to points

To include the fake-pass contribution from 02-3, we fit:

  `Points[n] = Base + β1·Draw[n-1] + β2·Draw[n-2] + β3·Draw[n-3]`

for `original`, `fake-draw`, and `fake-miss-draw`.

**β1 in point units (pts per draw-event one turn ago)**

| Variant | 2p | 3p | 4p |
|---|---:|---:|---:|
| original | 1.212 | 1.256 | 1.211 |
| fake-draw | 1.176 | 1.208 | 1.188 |
| fake-miss-draw | **0.717** | **0.687** | **0.687** |

Key takeaways:
- The fake-pass/fake-miss effect translates cleanly: **β1 drops from ~1.22 to ~0.70 points/event** (all player counts), matching the direction from probability space (0.21 → 0.13).
- The shrink ratio is similar but not identical: point-space ratio is about **0.57**, while probability-space ratio was about **0.62**. This mismatch is expected because fake-miss changes not only match probability but also the conditional point mix of matches.
- `fake-draw` remains close to `original` in point space too (differences ~0.02–0.05), reaffirming the causal interpretation from 02-2/02-3.
